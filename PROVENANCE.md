# Provenance

This repository contains an independent UI test suite for the educational Stellar Burgers web application.

The test scenarios reflect the educational/course task domain. The repository contains test code only: Selenium page objects, locators, pytest fixtures, API-based test-data preparation, and automated tests.

The upstream application source code, production modules, assets, and starter application were not copied into this repository.

The external application, its API, branding, and assets remain the property of their respective owners. This repository is not affiliated with or endorsed by them.
